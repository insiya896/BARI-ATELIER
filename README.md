# BARI ATELIER — Luxury Artificial Jewellery Store

BARI ATELIER is a luxury e-commerce catalog featuring anti-tarnish 18K gold-plated artificial jewellery designed in an **Emerald Green, Warm Gold, Rose Pink, and Burgundy** aesthetic.

## Features
- **Zero-Interest Cash on Delivery (COD):** Direct order routing to WhatsApp without payment merchant processing fees.
- **Live Search & Category Filtering:** Instant client-side filtering by name, material, or category (Necklaces, Rings, Earrings, Combos).
- **Interactive Detail Modal:** Displays exact measurements, material specifications, and care instructions.
- **Full-Screen Dedicated Checkout:** Complete checkout view replacing temporary side drawers.
- **Tailwind CSS & Custom Micro-Animations:** Smooth image scale effects and glassmorphic navigation header.
